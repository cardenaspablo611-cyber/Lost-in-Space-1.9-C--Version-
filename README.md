# Lost In Space

A Unity game where players pilot different spaceships through cosmic challenges, dodge enemies, and explore the universe.

## Project Description
Navigate through space, avoid enemies, collect power-ups, and survive as long as you can! Choose from different spaceships, each with unique abilities and weapons.

## Requirements
- Unity Version: 2022.3 LTS
- Platform: Windows

## How to Play 🎮

### Controls:
- Arrow Keys: Move your spaceship
  - ⬆️ Move up (W or Up Arrow)
  - ⬇️ Move down (S or Down Arrow)
  - ⬅️ Move left (A or Left Arrow)
  - ➡️ Move right (D or Right Arrow)
- SPACE: Shoot
- P: Pause game
- ESC: Open last menu / Pause game

### Special Abilities:
- Collect power-ups for special weapons:
  - 💥 Bombs: Press B to deploy
  - 🚀 Missiles: Press M to launch
  - ⚡ Electric Blast: Press E to activate
  - 🛡️ Shield: Automatically activates when collected

### Spaceships:
1. Normal Spaceship: Balanced stats
2. Fire Spaceship: High damage
3. Electric Spaceship: Special electric attacks
4. Stringray Spaceship: Fast movement
5. Tree Spaceship: High health

### Utility Scripts
The project includes several Python utility scripts to assist with development and maintenance:
- `lines_counter.py` - Analyzes and reports total line counts across project files
- `replacer_ie_with_y.py` - Performs automated text replacements for consistency
- `search_debug_log_in_cs_files.py` - Locates Debug.Log statements in C# source files

These scripts help automate common development tasks and maintain code quality.



## Installation
1. Clone this repository
2. Open the project in Unity
3. Open the main scene in Assets/Scenes/
4. Press Play in Unity Editor or build the game

## Project Structure
- `Assets/Scripts/` - Game logic and mechanics
- `Assets/Prefabs/` - Reusable game objects
- `Assets/Scenes/` - Game levels and menus
- `Assets/ScriptableObjects/` - Game data and configurations
- `Assets/Materials/` - Material settings
- `Assets/Physics/` - Physics configurations

## Development Setup
1. Make sure you have Unity 2022.3 LTS installed
2. Clone the repository
3. Open the project in Unity
4. Wait for all packages to be imported
